Cunnel

三合一浑然一体隧道与反向代理控制台
运行中 (Active) True Single Process

⚡ 内置引擎运行架构 (In-Process)

Cunnel 已实现控制面板、Caddy 反向代理网关及 Cloudflare 隧道调度全功能三合一，全系统仅有唯一一个进程，零外部子进程，零外部依赖。
🔀 进程内 Caddy 反代引擎 内置运行中
特性：纯内存原子零停机热重载、多域名/多路径分流、支持 WebSocket 双向流式透传。
🌐 进程内 Cloudflare 隧道调度器 协程托管中
特性：每条隧道拥有专属独立 Context 生命周期，具备 panic 隔离兜底防护。
